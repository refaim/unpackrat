Версия 0.3.1
-------------
 * Каталог ресурсов строится по метаданным. Содержимое ресурса разбирается
   при извлечении вместе с необходимыми для этого зависимостями.
 * Данные бандлов UnityFS читаются по блокам без полной загрузки каждого
   внутреннего файла. Типы ресурсов, исходные пути и объявленные размеры сохранены.
 * Метаданные каталога хранятся компактно; адаптивный Server GC с экономией
   памяти снижает её расход на x64 при повторном открытии архивов.
 * x86-кандидат прошёл 11 ресурсных тестовых примеров на Windows XP SP3.
 * По-прежнему экспериментальный кандидат для ручного тестирования.

Версия 0.3.0
-------------
 * Экспорт дополнительных типов ресурсов, каждый - в собственное расширение
   выходного файла: Texture2D и Sprite в PNG, TextAsset в .bin с исходными
   байтами, AudioClip в WAV или Ogg, встроенные шрифты в TTF/OTF/TTC,
   VideoClip и MovieTexture в исходный контейнер, геометрия Mesh в GLB.
 * Сохраняется исходная иерархия ресурсов с буквальным запасным вариантом
   {Type}; конвертация записей выполняется по требованию.
 * Публичного релиза пока нет: кандидат в ветке разработки; сборки -
   экспериментальные варианты для ручного тестирования, передаются
   напрямую.

Версия 0.2.0
-------------
 * Сохраняется исходная иерархия ресурсов Unity; если она недоступна,
   используется буквальный запасной вариант {Texture2D}/{TextAsset}.
 * Size и PackedSize сообщают объявленную длину источника (0 означает
   неизвестно); конвертация текстур по-прежнему ленивая.

Версия 0.1.0
