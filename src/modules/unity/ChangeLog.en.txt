Version 1.0.1
-------------

 * Structural duplicate filter: exact source, rectangle, canvas and orientation matches are collapsed, preferring Sprite over an equivalent full Texture. Unknown tight/transformed Sprite data remains listed; opening does not decode PNG pixels.
 * Validates source-returned path lengths against the shared Observer metadata bound.

Version 1.0.0
-------------

 * Opens Unity serialized files and asset bundles.
 * Extracts Texture2D and Sprite resources as PNG.
 * Extracts TextAsset resources as their original raw bytes.
 * Extracts AudioClip resources as WAV or Ogg, with legacy raw and FSB fallbacks.
 * Extracts font resources as TTF, OTF, or TTC.
 * Extracts VideoClip resources as raw containers and MovieTexture resources as OGV.
 * Exports Mesh resources as GLB geometry.
 * Exports requested resources on demand and keeps original resource paths when available, with {Type} fallbacks otherwise.
 * Preserves SDK version-aware handling, removes the duplicate ZSTD codec, and ships self-contained x86 and x64 builds, each a single DLL, with no .NET install required.
